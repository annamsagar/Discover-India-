# DISCOVER INDIA – AI-POWERED TOURISM & SMART TRIP PLANNER

## Project Overview
A complete, professional, secure, responsive, full-stack tourism platform focused on India.

## Features
- Discover Indian tourist destinations
- Route Optimization & Itinerary Generation
- AI-Powered Tourism Assistant
- Personalized Recommendations
- RBAC (Role-Based Access Control: USER, CONTENT_MANAGER, ADMIN)
- Search & Filter destinations
- Nearby Hotels, Hospitals, Emergency Services
- Ratings & Reviews

## Technology Stack
- **Frontend**: React, Vite, Tailwind CSS, React Router, Axios
- **Backend**: Java 17+, Spring Boot 3.3+, Spring Web, Data JPA, Security, JWT
- **Database**: PostgreSQL

## Environment Setup
Copy `.env.example` to `.env` (in the root directory or configure per environment) and fill in your details.

## Running the Application
### Backend
```bash
cd backend
./mvnw spring-boot:run
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
